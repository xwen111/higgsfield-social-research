# Higgsfield 社媒视觉研究

在线阅读：https://xwen111.github.io/higgsfield-social-research/

36 条 Instagram 样本与封面、16 个可追溯的观察，以及 Hook、节奏、MG 动画和多 showcase 组织方式的拆解。16 条观察附 54 张配图，每张注明样本、时间点与观察重点，支持放大和原帖追溯。

本仓库保存可公开阅读的网站构建产物。入口为 `index.html`，报告正文为 `research/report.html`；`research/` 中的图片、研究片段和音轨是网页使用的资源。研究生成脚本、原始长视频和抓取清单保留在本机。

## 阅读与更新

GitHub Pages 从 `main` 分支的根目录发布，更新网页文件后会重新部署。下载整个仓库后，也可通过本地静态服务器阅读；请保留目录结构以确保图片与播放器可用。
